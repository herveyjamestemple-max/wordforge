WordForge does not have a submission backend yet. This page explains the information a future submission would need—nothing entered here is sent or stored.

What projects may be submitted?

Apps, software, websites, developer projects, and digital resources that are lawful, accurately described, and submitted by their owner or an authorized representative.

Information to prepare

  • Project name and clear, accurate description
  • Developer name and a real contact method
  • Official project website and official download sources, if any
  • Supported platforms, current version, and update date
  • License, ownership confirmation, and required attribution
  • Screenshot and icon assets you have permission to use
  • Privacy practices, data handling, permissions, and requirements
  • Known security issues, risks, or material limitations

How review would work

  1. Provide project details through an owner-configured submission channel.
  2. WordForge would review completeness, source links, rights information, and compliance with the developer rules.
  3. We may ask for clarification, decline, or remove a listing if information is incomplete, misleading, unsafe, or unauthorized.
  4. Developers should update changed details or request removal through the designated owner contact.

Review is not a security audit, endorsement, certification, or guarantee that software is safe.

Submission channel not configured

The site owner must add an actual contact address or trusted submission provider before accepting entries.
